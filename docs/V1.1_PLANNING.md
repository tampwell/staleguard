# v1.1 planning framework

## Gate before ANY v1.1 work starts
Gate 2 trajectory must look alive: meaningful install growth by month 1-2
(target: 1,000 by month 4; <300 = stop and reassess the thesis, not build
more). Track with `scripts/track-metrics.sh <ourPluginId>` once published.
Baseline for calibration: the active rival (id 18525) gains roughly 60
installs/day at 183K total (measured 2026-08-14).

## Scoring model (demand-first)
Score = 2×Demand + Effort + 2×Strategic
- Demand: 1 = we think it's nice / 2 = several independent user requests /
  3 = recurring theme in reviews+issues. NO score of 2-3 without linkable
  user evidence — we do not invent demand.
- Effort: 3 = days / 2 = 1-2 weeks / 1 = >2 weeks.
- Strategic: 3 = differentiating / 2 = strengthens core / 1 = nice-to-have.

## Process
1. Collect every request verbatim (issue link) for 2-4 weeks post-launch.
2. Score with real demand evidence; sort; owner picks the top 2-3.
3. v1.1 ships small and fast — the release muscle matters more than size.
